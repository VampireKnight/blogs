如何使用GitHub的Pages功能实现静态网站托管

步骤

1.创建一个新的仓库 或 使用现有的仓库。

2.准备你的静态网站文件（如 index.html, style.css, script.js 等）并将其推送到仓库中。

3.配置 GitHub Pages 设置：

参考:https://github.com/VampireKnight/blogs/settings/pages 进入你的仓库主页,点击顶部的 "Settings" 标签 在左侧菜单中找到并点击 "Pages" 选择source 与 项目路径

访问路径

https://<username>.github.io/<repository-name>/

选项配置说明

Build and deployment 之 Branch

分支选择的影响是直接的 目录路径的选择好像没区别

经验证:选了/docs 的话,默认访问的优先级是 /docs/index.html -> /docs/README.md -> /docs/404.md -> github的404 选 /(root) 或 /docs 没区别,都是直接访问项目的根目录? 不是.先设置了/(root),访问成功;后变更为/docs,保存后,依旧能访问到;这是因为 github有缓存 或者 没有变更过来,

其他方案:https://hexo.io/zh-cn/docs/github-pages
